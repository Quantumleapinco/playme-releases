Nagenli for Nvidia Shield

At the end, Nagenli is an app on your Shield and shows your library from your computer. This is the Android TV guide, told for the Shield. Install Nagenli on the computer first.

About 10 minutes

You need

  • Nagenli already installed on your computer, and the computer on
  • The Shield connected to the TV and to the same home network as the computer
  • The Shield's remote, and the computer's address (step 1 shows where)
  • A phone that is already connected to Nagenli, if you want to connect by picture code

On a phone or tablet? Use the Android phone guide: the app there comes from Google Play.

Install

  1. Write down your computer's address

    In Nagenli on the computer, under Settings, there is an address like http://192.168.1.20:8686. Write it down or keep it on your phone.

    You will seeAn address that starts with http:// and ends with :8686.

  2. Install Downloader from Google Play

    On the TV, open Google Play, search for Downloader (by AFTVnews, orange icon) and install it. Downloader is a free helper that fetches a file from an address.

    You will seeDownloader on the TV's home screen or in its apps.

  3. Let Downloader install apps

    Do this now so the TV does not refuse later. On most Shields, open Settings, then Device Preferences, then Security & restrictions, then Unknown sources, and switch Downloader on. Menus differ a little between Shield versions: if you do not find it, look for Unknown sources in Settings, or skip this step and do it when the Shield asks (step 5).

    You will seeA list of apps, with a switch beside Downloader.

  4. Open Downloader and type the address

    In the address box type your computer's address followed by /app/Nagenli.apk, then choose Go. Use the on-screen keyboard with the remote.

    Example: your computer's address, then /app/Nagenli.apk

    http://192.168.1.20:8686/app/Nagenli.apk

    You will seeA download bar, then an install window.

    If this happens

    It says the app is not there yet?

    Nagenli on the computer was installed only minutes ago and is still fetching it. Wait five minutes and try again, or type this address instead:

    The other address, if the first says the app is not there yet

    quantumleapinco.github.io/nagenli-releases/Nagenli.apk

  5. Let Downloader install apps, if the TV asks

    The first time, the TV may refuse and ask to let Downloader install apps. Choose Settings, switch Downloader on in the list, and go back.

    You will seeYou are back at the install window.

    If this happens

    The TV refused?

    That is normal the first time. Switching Downloader on once is all it needs.

  6. Choose Install

    Choose Install, then Open.

    You will seeNagenli opens on the TV and looks for your computer by itself.

  7. If it asks to be paired, scan its picture code

    The TV shows a picture code (a QR). On a phone that is already connected to Nagenli, open the camera, point it at the TV, tap the link and choose Connect in Nagenli. Nothing is typed on the TV.

    You will seeThe TV connects and shows your library.

    If this happens

    No phone at hand?

    Type the six-digit pairing code instead. It is shown in Nagenli on the computer, under Settings › Devices and access. It works for one device and for ten minutes.

Watching away from home

Optional. In another home the TV can reach your computer over the internet.

  1. On your computer, switch on Watch from anywhere

    Open Nagenli's Settings › Devices and access and switch Watch from anywhere on.

    You will seeWait until it says Ready. Under it is a connect code, like K7Q-4M2-X9T.

  2. On the TV, open Nagenli and type the connect code

    When it cannot find the computer, type the connect code in the box and choose Connect.

    You will seeThe TV asks to be paired and shows a picture code (a QR).

  3. Scan the picture code with a connected phone

    The easiest way: on a phone that is already connected to Nagenli, open the camera, point it at the TV's picture, tap the link and choose Connect in Nagenli. Nothing is typed on the TV.
    If this happens

    No phone?

    Type the six-digit pairing code instead. It is in Nagenli's Settings › Devices and access on the computer.

You never see or type the computer's address, and if your internet provider changes it the TV finds the computer again by itself.

Updates

What you see on the Shield (the library, the player, search) comes from your computer and is always up to date. The app itself changes rarely. A Shield has no web browser, so to update the app repeat the Downloader step (type the same address again): the new app installs over the old one and nothing is lost.

Stuck? That is fine, it happens

The Shield will not install the app

The Shield has to be told once that Downloader may install apps. On most Shields: Settings, Device Preferences, Security & restrictions, Unknown sources, switch Downloader on. Menus differ a little between versions, so look for “Unknown sources” if the names are not exactly these. Then choose Install again.

Downloader says the app is not there yet

Nagenli on the computer was installed only minutes ago and is still fetching it. Wait five minutes and try again, or type quantumleapinco.github.io/nagenli-releases/Nagenli.apk instead.

Nagenli on the Shield cannot find my computer

Check that the computer is on and Nagenli is running there, and that the Shield is on the same home network (Wi-Fi or cable). In another home, use the picture code or the connect code (see “Watching away from home” above).
